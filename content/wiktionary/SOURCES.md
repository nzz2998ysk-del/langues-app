# Vocabulary imported from free sources

`content/wiktionary/<code>.json` is generated by `scripts/course/import-wiktionary.js`
and merged into `course/data/<code>.json` by `scripts/course/build.js` (hand-authored
words always win).

| Data | Source | License |
|---|---|---|
| Words, parts of speech, English meanings, romanizations | Wiktionary, via [Vuizur/Wiktionary-Dictionaries](https://github.com/Vuizur/Wiktionary-Dictionaries) (`<Language>-English Wiktionary dictionary.tsv`, built from [Wiktextract / kaikki.org](https://kaikki.org)) | CC BY-SA 3.0 + GFDL (Wiktionary contributors) |
| Frequency ranks (word order, CEFR levels) | [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords), OpenSubtitles 2018 (`content/2018/<lang>/<lang>_50k.txt`; 2016 for eo, hi, ja) | CC BY-SA 4.0 |

Adaptations: lemmatisation (inflected forms ranked under their lemma), removal of
proper nouns, vulgar/obsolete/"form of" senses; CEFR level from the frequency rank;
French meanings pivoted through the French-English Wiktionary dictionary.
The derived word lists are distributed under **CC BY-SA** (ShareAlike), with the
attribution above (also shown on the app's legal page, `/mentions-legales`).

Not covered (no dictionary in the source repository): Dutch, Finnish, Swedish; Norwegian
Bokmål only partially. Constructed languages (Klingon, High Valyrian) are not in
Wiktionary's dictionaries.

Refresh:

```sh
git clone --depth 1 https://github.com/Vuizur/Wiktionary-Dictionaries data-src/wd   # the needed .tsv files
curl -o data-src/freq/es.txt https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/es/es_50k.txt   # one per language
node --max-old-space-size=6144 scripts/course/import-wiktionary.js --src data-src
node scripts/course/build.js
```
