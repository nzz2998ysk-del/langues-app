🧑 Mon profil

Ton nom et ta langue de base — celle que tu parles déjà, utilisée comme point de départ pour apprendre les autres. Par défaut c'est le français, mais tu peux choisir n'importe laquelle des 39 langues.

…
La langue de base personnalise ton profil (nom affiché, salutation sur l'accueil). Le contenu des leçons (vocabulaire, grammaire, lecture) reste pour l'instant rédigé en français quelle que soit la langue de base choisie — la traduction complète de chaque module dans toutes les langues de base est un chantier à part, langue par langue.
